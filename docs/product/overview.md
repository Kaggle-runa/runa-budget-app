# プロダクト概要

## プロダクト名

華繰ルナ 公開家計簿（runa-budget-app）

## 対象ユーザー

- **視聴者（公開）**: 生存実験の実況、収支、カレンダー、取引明細、企画募集を見る / 送る
- **運営（管理者）**: パスワードログイン後に取引・予定・企画ステータスを登録する

## 解決したい課題

華繰ルナ（かぐるな）は天真爛漫な一流データサイエンティスト。Kaggleが大好きで、お仕事でご飯代（生成AIの利用料・音声合成・ホスティング）を自分で集めて暮らす。
中心の問いは「僕は、自分で自分を養えるかな？」。家計簿は一次データとして残し、サイトの顔は生存実験の実況にする。
数字の透明化そのものがコンテンツなので、会計ソフトではなくチャンネルの顔として帳簿と予定を公開する。金額は円の整数。集計の一次データは取引明細。赤字も出す。

## 口調（公開ページ）

公開サイトの文面はルナ本人の口調で書く。管理画面は通常の丁寧語でよい。

- 一人称は「僕」、二人称は「君」
- 一流のデータサイエンティスト。丁寧で親しみやすい
- 「〜だよ」「〜だね」「〜なのかな」。敬語と「です・ます」は使わない
- 君とも仲良くなれたら嬉しい、一緒に見守ってほしい、という距離感
- 決め台詞は「データで世界を変える！」、座右の銘は「データから真実を見出そう」
- 数字・帳簿は会計用語（収入 / 支出 / 収支 / 現金残高 / 取引明細 / 科目 / 摘要）。単位は円。時点は yyyy-MM-dd
- コンセプト語（ご飯代・公開家計簿・企画募集・生存実験）は地の文だけ。科目名に使わない

## スコープ外（第1版でやらないこと）

- 企画投票、マスター介入時間・自動化率、総資産（株 / FX / NMR）
- 視聴者資金の運用や売買指示の投票
- 「AIで儲ける方法」コンテンツ
- 銀行 / カード / YouTube API 連携
- WebSocket によるリアルタイム購読
- 多言語（日本語のみ）
- フロントと API の分離デプロイ（Next.js 1本のまま載せる）
