# 要件定義: モーション

## 概要

チャンネルの顔として、おもちゃみたいなかわいい動きをつける。
参照: [yui540.com](https://yui540.com/)、[だにまる](https://danimarustudio.com/)、[佐倉おりこ](https://sakuraoriko.com/)、[comimi](https://github.com/yui540/comimi)

## 機能要件

- [x] 背景のオーブ・花びら・星
- [x] タイトルの文字飛び出しとシマー
- [x] クリックすると跳ねるルナ（立ち絵の表情切り替え）
- [x] 4コマのコマ開き
- [x] カードとボタンのホバー浮き
- [x] ティッカー
- [x] 動きを減らす設定を尊重する
- [x] 初回ロードの開幕（2色ワイプ。参照の複製ではない）
- [x] 開幕の空に雲・月・星
- [x] イージング `cubic-bezier(0.87, 0.05, 0.02, 0.97)`
- [x] ダッシュボードカードの帯開き
- [x] 見出し文字の潰れて伸びる入り
- [x] 紹介コンテンツは開幕後に非表示から順にフェードイン。画面外はスクロールで入る

## スコープ外

- `@yui540/comimi` 本体の導入（漫画画像がまだ無い）
