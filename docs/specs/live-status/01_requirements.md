# 要件定義: 実況トップ・経済活動ログ・Numerai

## 概要

トップを「会計の要約」から「AIの経済活動の実況」に一段寄せる。
帳簿（取引明細・貸借対照表）は壊さず詳細ページに残し、総資産の内訳に Numerai（NMR・モデル成績）を足す。
意思決定と日次の出来事は「経済活動ログ」として履歴に残す。

## 背景・目的

現在値だけだと一回見たら終わる。VTuber として面白いのは、暴落・ホールド・利確が実際の歴史になること。
Numerai は単なる含み資産ではなく、「ルナ自身が AI なのに AI モデルを育てている」構造の核になる。

## ユーザーストーリー

- 視聴者として、最初の画面で総資産・今日の増減・自給率・自力活動可能期間を知りたい。
- 視聴者として、今日ルナに何が起きたか（仕事の入出金と Numerai の動き）を実況として見たい。
- 視聴者として、NMR の暴落やホールド判断をあとから掘りたい。なぜなら現在値だけでは物語にならないから。
- 視聴者として、ルナの Numerai モデルの CORR / MMC / Stake / ランクを専用ページで見たい。
- 管理者として、売買や「ホールドします」などの意思決定をログに残したい。

## 会計の約束

損益（自給率・今月の運営・カレンダー）はこれまでどおり取引明細の収入 / 支出だけ。
NMR の値動き・未確定の payout は損益に入れない。総資産の内訳とログに出す。

第1版の総資産:

`総資産 = 現金 + 機材 + NMR（円換算、時点を明記）`

株・FX は第1版では入れない（プレースホルダのみ可）。

## 画面の3階層

| 層 | 置き場 | 中身 |
|----|--------|------|
| ① 一瞬で分かる状態 | `/` 最上部 | 総資産、今日の増減、自給率、自力活動可能期間 |
| ② 今何が起きているか | `/` その下 | 「今日のルナ」。仕事の入出金、Numerai の日次、ログ |
| ③ 詳細 | 既存ページ + 新ページ | 資産 / 仕事（`/dashboard`） / Numerai / 投資（後回し） / 取引明細 |

トップ＝実況。`/dashboard`＝会計。既存の貸借対照表・サンキー・月次はそのまま。

## Numerai の正本

公開サイトのモデル名・提出履歴・実験メモは、別リポジトリ `numerai-strategy` を正とする。コードや pickle はコピーしない。取るのは公開してよい数字とログの種。

いま提出されているモデル（`experiments/uploads/history.json` / `models/README.md`）:

| 提出名 | メモ |
|--------|------|
| `runa_version1` | 1号機。旧 `soramame`。現行メイン |
| `runa_version2` | 2号機。新規 |

成績の生データは Numerai 公開 API。実験の物語は `numerai-strategy` 側。

## NMR の取り方

公開 GraphQL（認証なし）で取れるもの:

| 数字 | 型 | 経路 |
|------|----|------|
| モデルの Stake | `Nmr` | `v3UserProfile.stakeValue`。画面の「3.45 NMR」と同じ。未確定ラウンド込み |
| モデルの成績 | 数値 | `latestReps` / `latestRanks` / `latestReturns` |
| NMR の公式USD価格 | 文字列 | `latestNmrPrice.priceUsd` |

公開では取れないもの（`account` はログイン中の自分の口座）:

| 数字 | 型 | 経路 |
|------|----|------|
| 未ステーク（Numerai口座） | `Nmr` | `account.availableNmr`。スコープ `read_user_info` |
| 出金待ち | `Nmr` | `account.heldForPendingWithdrawals` |
| オンチェーン残高 | `Nmr` | `account.onChainWalletBalance` |

`v3UserProfile` に `nmrStaked` は無い。以前 USD と読んでいた `stakeValue` は **NMR**。

円換算:

`円 = (stakeValue の合計 + availableNmr) × NMR/USD × ドル円`

NMR/USD は Numerai の `latestNmrPrice`、だめなら CoinGecko。24h 変化は CoinGecko。ドル円は open.er-api.com、だめなら Frankfurter。
帳簿の損益には入れない。提出用の秘密情報は置かない。
