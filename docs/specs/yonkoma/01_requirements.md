# 要件定義: 4コマ漫画

## 概要

紹介ページにルナの4コマを並べる。管理画面から作品を追加・編集・削除できる。

## 機能要件

### 必須（MUST）

- [x] 1作品は4コマを縦に並べた画像1枚
- [x] `/` にサムネ一覧。クリックでモーダル表示（前後移動可）
- [x] `/` に公開中の作品を新しい順（sortOrder → 作成日）で出す
- [x] 管理画面 `/admin/yonkoma` で作成 / 編集 / 削除。非公開にできる
- [x] 画像はファイルアップロード（Storage）。既存の公開パスも可

## スコープ外

- コマごとの個別ページ
- コメント
