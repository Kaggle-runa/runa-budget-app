# 要件定義: お知らせ

## 概要

配信やサイトの更新を、カード一覧で公開する。問い合わせの投稿フォームとは別。

## 機能要件

### 必須（MUST）

- [x] `/news` に新しい順の一覧。絞り込み: すべて / お知らせ / 配信 / その他
- [x] カードにタイトル・区分・日付。画像があればサムネ
- [x] `/news/[id]` で本文とカバー画像
- [x] トップに最新3件
- [x] 管理画面で作成 / 編集 / 削除。非公開にできる
- [x] 管理画面から画像ファイルをアップロード（Supabase Storage）。URL指定も可
- [x] 本文は Markdown の太字 `** **` とリンク `[文字](URL)` が使える

## スコープ外

- 本文中のインライン画像
- コメント、RSS
