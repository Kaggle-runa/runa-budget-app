# 要件定義: 収支ダッシュボード

## 概要

収入の出所と支出の行き先を、チームみらいの公開収支に近い情報密度で見せる。

## 機能要件

### 必須（MUST）

- [x] 大きな白カードにタイトル / 時点 / 説明
- [x] 収入総額・支出総額・収支
- [x] 収支の流れ（左: 収入 + マスター借入、中央: 合計、右: 支出 + 現金）
- [x] 今月の運営カウンター（収入 vs 運営費）
- [x] 貸借対照表カード（docs/specs/balance-sheet/）
- [x] 月次は収入棒（上）・支出棒（下）・収支の線。当年1〜12月
- [x] 収入・支出カテゴリの内訳
- [x] 明細への導線

## スコープ外

- 法定区分タブ、ランウェイ
