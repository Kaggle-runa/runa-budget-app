# 設計: 貸借対照表

> 01_requirements.md の要件を満たす技術設計。`.cursor/rules/` に沿って書く。

## 画面構成

| パス | 画面 | 概要 |
|------|------|------|
| `/dashboard` | 収支 | 既存カードの上またはサンキーの下に B/S カード |
| `/ledger` | 取引明細 | 借入・返済・機材購入も行として出す |
| `/admin/transactions` | 取引 CRUD | 区分に借入 / 返済 / 機材購入を追加 |

独立ルートは作らない。

## 見た目（チームみらい寄せ）

貸借対照表カード:

- `DashCard` + `DashSectionHeader`（タイトル「貸借対照表」、説明はルナ口調）
- 2列の比例ブロック。高さは `資産合計` を 100% にする
- 左: 現金（ミント）→ 機材（濃いティール）→ NMR時価（インディゴ）。0円の科目は出さない
- 右: マスター借入（サーモンピンク）→ 累計収支（青）→ NMR評価差額（薄いインディゴ）。純資産が負なら累計収支ブロックは出さず金額だけ赤字
- NMR は `todayFeed.nmr.yenNow`。取れないときはブロックなし
- ブロック内は科目 + `formatYen`。高さ 48px 未満は1行
- 単位は円のまま。万円にはしない

サンキー:

- 左ノード: 収入科目（ティール）+ マスター借入（グレー）
- 中央: 合計（収入 + 借入）
- 右ノード: 支出科目（赤）+ 返済（グレー）+ 機材（ティール）+ 現金（グレー）
- 帯の高さは金額比例（既存の `layoutGapped`）

KPI ストリップ（収入 / 支出 / 収支）は損益のまま。デザイン変更はしない。

運営カウンター（`ops-counter.tsx`）:

- 偽アリスのサーバーカウンターの思想だけ借りる。今月の収入と今月の運営費（支出）を大きな数字で並べる
- 下にその月の支出科目内訳
- 収入 < 運営費のときは、続きのための数字だよ、と地の文で書く
- 見た目は既存の白カード。ネオンやダークUIにはしない

## 更新経路

既存の `upsertTransactionAction` / `deleteTransactionAction` を拡張する。新しい Action は作らない。

| 関数 | 概要 | 入力 |
|------|------|------|
| upsertTransactionAction | 区分に `loan` / `repay` / `capex` を追加。保存前に現金・借入残高を検算 | 既存 FormData + type |
| deleteTransactionAction | 削除後に現金が負にならないこと | id |

## データモデル

`Transaction.type` の値を広げる。テーブル追加はしない。

| type | 科目 | 現金 | 機材 | 借入 | 累計収支 |
|------|------|------|------|------|----------|
| income | 既存の収入科目 | + | | | + |
| expense | 既存の支出科目 | − | | | − |
| loan | `master_loan`（マスター借入） | + | | + | |
| repay | `master_repay`（マスター借入） | − | | − | |
| capex | `equipment`（機材） | − | + | | |

集計は `lib/finance.ts` に `balanceSheet()` と `cashFlowGraph()` の更新を置く。

検算（Action 内）:

1. 対象行を除いた現状の B/S を取る
2. 今回の行を足した（または削除した）あとの現金 ≥ 0
3. マスター借入 ≥ 0

## コンポーネント構成

```
components/dashboard/
├── balance-sheet.tsx      # 比例ブロック
├── cash-flow-sankey.tsx   # グレーの借入・現金
└── cash-flow-card.tsx     # B/S を載せる

lib/categories.ts          # loan / repay / capex の科目
lib/finance.ts             # balanceSheet / サンキー
types/domain.ts            # TxType と BalanceSheet
```

公開明細と管理一覧は、区分ごとの色だけ分ける（収入ティール、支出赤、それ以外グレー）。
