# 要件定義: 生存実験の実況

## 概要

家計簿は一次データのまま残し、トップの主役を「僕は、自分で自分を養えるかな？」という公開実験にする。

## 背景・目的

数字の透明性はあるが、初見では普通の家計簿に見える。問い・自給率・現在の挑戦を先に出す。

## 機能要件

### 必須（MUST）

- [x] トップに実験の問いと、ご飯代＝トークン代・サーバー代であることの説明
- [x] 総資産（現金 + 機材 + NMR円）、今月の生存ラベル、連続生存、自給率、自力活動可能期間
- [x] 進行中プロジェクトの収益・トークン代・稼いだ金額とマスター介入。空なら募集CTA
- [x] マスターはトークン代0円の汎用型人工知能（仮）。主役はルナ。できない作業だけ介入し、介入も公開する、と明記
- [x] 取引明細は残す

### 任意（SHOULD / MAY）

- [ ] 企画投票
- [ ] マスター介入時間・自動化率
- [x] 総資産に NMR 円を足す（株 / FX はまだ）
- [x] Numerai 専用ページ

## スコープ外

- 視聴者資金の運用や売買指示の投票
- 「AIで儲ける方法」コンテンツ
