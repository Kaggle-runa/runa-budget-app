# 設計: 生存実験の実況

## 画面構成

| パス | 概要 |
|------|------|
| `/` | 実験の問い、総資産、いまのルナの状況、現在の挑戦、マスター説明 |

ヒーロー → 総資産 → いまのルナの状況 → 現在の挑戦 → Numerai入口 → マスター → お知らせ → 4コマ。

## 集計

`lib/survival.ts`。一次データは取引明細。「今日」と「今月」は日本時間（`Asia/Tokyo`）。

- ご飯代: `llm_api` / `voice` / `hosting`（`tools` と `other` は含めない）
- 現金: 当日までの現金（収入 + 借入 − 支出 − 返済 − 機材）
- 機材: 当日までの `capex` 累計
- 総資産: `現金 + 機材 + NMR円`。NMR円は [live-status](../live-status/) の換算。取れないときは 0 として足し、画面では「—」
- 今日の増減（帳簿）: 当日の取引の符号付き合計。トップの「今日の資産増減」は仕事の収支 + NMR評価額の前日比
- 自給率: 今月の収入 ÷ 今月のご飯代。ご飯代が 0 なら `null`
- 今月の生存ラベル: 自給率 100%以上なら「今月は自力で生存中」、未満なら「今月はご飯代が足りてないよ」、`null` なら緑にも赤にもしない
- 自力活動可能期間: 現金 ÷ 直近30日の1日あたりご飯代。ご飯代 0 なら `null`
- 連続生存日数: 当日までの現金が負にならない連続日数。総資産ではなく所持金ベース
- 自給率カードの文面（100%以上）: 「今月も、自分で稼いだお金だけで生存できそうだよ。」
- 現在の挑戦: `Project.status = active`。完了は「これまでの結果」
- 企画モニタ: 収益（収入）、トークン代（`llm_api` + `voice`）、稼いだ金額（収益 − トークン代）。その他経費があれば小さく出す
- マスター介入: `Project.masterNote`。公開文面。無いときは「まだ頼ってないよ」
- 累計: 収入合計、ご飯代合計、売上 − ご飯代（ツール代などは含めない）。トップの主役にはしない

借入は総資産に入れない。NMR は総資産に入れるが、損益・自給率には入れない。株・FX はまだ入れない。
