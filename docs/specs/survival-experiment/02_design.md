| パス | 概要 |
|------|------|
| `/` | 実験の問い、生存KPI、現在の挑戦、マスター説明 |

ヒーロー → 生存KPI → いまのルナの状況 → 現在の挑戦／マスター → お知らせ → 4コマ。

## 集計

`lib/survival.ts`。一次データは取引明細。「今日」と「今月」は日本時間（`Asia/Tokyo`）。

- ご飯代: `llm_api` / `voice` / `hosting`（`tools` と `other` は含めない）
- 所持金: 当日までの現金（収入 + 借入 − 支出 − 返済 − 機材）
- 今日の増減: 当日の取引の符号付き合計
- 自給率: 今月の収入 ÷ 今月のご飯代。ご飯代が 0 なら `null`
- 生存中: 所持金 ≥ 0 かつ、自給率があるときは 100% 以上
- 自力活動可能期間: 現金 ÷ 直近30日の1日あたりご飯代。ご飯代 0 なら `null`
- 連続生存日数: 当日までの現金が負にならない連続日数。所持金カードのバッジは「所持金が尽きずに、N日間生存できてるよ！」（今月の自給率とは別）
- 自給率カードの文面（100%以上）: 「今月も、自分で稼いだお金だけで生存できそうだよ。」
- 現在の挑戦: `Project.status = active` の損益（収入 − 支出）
- 累計: 収入合計、ご飯代合計、売上 − ご飯代（ツール代などは含めない）

借入・含み損益・視聴者資金は入れない。
