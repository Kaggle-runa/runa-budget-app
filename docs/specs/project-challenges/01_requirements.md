# 要件定義: 挑戦の実況

## 概要

視聴者案（Idea）とは別に、実際にやる仕事を挑戦（Project）として登録する。
トップの結果欄で、収益・トークン代・稼いだ金額と、マスターがどこに介入したかを出す。

## 背景・目的

企画を送るだけでは、何に挑戦していくら使ったかが見えない。
明細に企画を付けて集計し、介入も同じカードに書く。

## ユーザーストーリー

- 視聴者として、いまの挑戦の売上とトークン代を見たい。なぜなら稼げてるか知りたいから。
- 視聴者として、マスターがどこを手伝ったか知りたい。なぜなら全部AIなのか確認したいから。
- 管理者として、挑戦を登録し、介入メモを書いて、明細を紐づけたい。

## 機能要件

### 必須（MUST）

- [x] 管理画面 `/admin/projects` で挑戦の作成 / 編集 / 削除
- [x] 状態は `planned` / `active` / `completed`
- [x] 進行中はトップの「現在の挑戦」（複数可）。完了はトップに全部出さず、企画ページの「これまでの結果」へ
- [x] 紐づく明細から 収益 / トークン代 / 稼いだ金額 を出す
- [x] トークン代は `llm_api` + `voice`。ホスティングは企画に付けたときだけその他経費
- [x] 稼いだ金額 = 収益 − トークン代。損益（収入 − 全支出）は変えない
- [x] マスター介入は挑戦のメモ1つ。公開する。無いときは頼っていないと書く
- [x] 詳細ページは結果と金額が主役。企画の概要と note / YouTube は、結果・明細カードの下の別カード。仕組みの長文は外部リンク（YouTubeは埋め込み＋リンクボタン）

### 任意（SHOULD / MAY）

- [ ] 介入を複数件のログにする
- [ ] 介入時間・自動化率

## 非機能要件

- 口調: 公開文面は「僕 / 君 / だよ」
- セキュリティ: 登録・更新・削除は管理画面

## 受け入れ条件

- [x] 進行中の挑戦がトップに出る
- [x] 同じ企画の収入と生成AI利用料がカードの数字と一致する
- [x] 介入メモが公開カードに出る
- [x] 帳簿の損益式は変わらない

## スコープ外

- 視聴者への収益分配
- 経済活動ログ全体（ホールド等）
