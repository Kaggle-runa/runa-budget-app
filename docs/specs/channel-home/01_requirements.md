# 要件定義: チャンネルトップ

## 概要

チャンネルの顔。華繰ルナの生存実験の問い、総資産、いまのルナの状況、現在の挑戦、マスター説明を先に出し、帳簿と各機能へ誘導する。

生存実験の指標の正本は [survival-experiment](../survival-experiment/) を見る。
総資産の式は [live-status](../live-status/) を見る。

## ユーザーストーリー

- 視聴者として、誰のサイトかと「自分で養えるかな」という問いを最初に知りたい。
- 視聴者として、最初の数秒で総資産・今月の生存・今日の増減を知りたい。
- 視聴者として、YouTube や X にすぐ行きたい。

## 機能要件

### 必須（MUST）

- [x] 実験の問いとご飯代＝トークン代・サーバー代であることの説明（自己紹介はフッター）
- [x] YouTube / X / note / Qiita / Zenn / GitHub リンク（フッター）
- [x] 総資産（現金 / NMR / 機材）をトップの主役にする
- [x] 今月の生存ラベル（自給率ベース）と連続生存日数
- [x] 今月の自給率、自力活動可能期間
- [x] 「いまのルナの状況」（お仕事とNMRを分け、今日の資産増減とルナのひとことを出す）
- [x] 進行中プロジェクトの収益・トークン代・稼いだ金額・マスター介入。空なら募集CTA。完了は結果として出す
- [x] マスター説明（ヒーローに短い注釈、詳細は下）
- [x] 今日のルナ / 次の仕事 / Numerai / カレンダー / お知らせ / 取引明細への入口
- [x] トップの月の窓に立ち絵（普通 / 喜び / 困り）。クリックで切り替え。取引が無いときは困り顔
- [x] 公開中の4コマを紹介の下に並べる（管理画面から追加）

## 受け入れ条件

- [x] `/` がスマホ幅でも崩れない
- [x] スマホはハンバーガー。開くと中央にページ選択、閉じるボタンあり
- [x] フッターに免責がある
- [x] ヒーローに自己紹介の長文を置かない
- [x] 所持金（現金）だけをトップの最重要数字にしない
