# 要件定義: チャンネルトップ

## 概要

チャンネルの顔。華繰ルナの生存実験の問い、生存KPI、現在の挑戦、マスター説明を先に出し、帳簿と各機能へ誘導する。

生存実験の指標の正本は [survival-experiment](../survival-experiment/) を見る。

## ユーザーストーリー

- 視聴者として、誰のサイトかと「自分で養えるかな」という問いを最初に知りたい。
- 視聴者として、YouTube や X にすぐ行きたい。

## 機能要件

### 必須（MUST）

- [x] 名前・キャッチ・紹介文
- [x] 実験の問いとご飯代＝トークン代・サーバー代であることの説明
- [x] YouTube / X / note / Qiita / Zenn / GitHub リンク（フッター）
- [x] 所持金、今日の増減、自給率、自力活動可能期間
- [x] 「いまのルナの状況」（お仕事とNMRを分け、今日の資産増減とルナのひとことを出す）
- [x] 進行中プロジェクトの売上・投入費用・損益
- [x] マスター説明
- [x] 収支・カレンダー・企画・お知らせ・取引明細への入口
- [x] トップの月の窓に立ち絵（普通 / 喜び / 困り）。クリックで切り替え。取引が無いときは困り顔
- [x] 公開中の4コマを紹介の下に並べる（管理画面から追加）
