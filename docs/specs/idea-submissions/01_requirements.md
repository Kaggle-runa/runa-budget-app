# 要件定義: 企画募集

## 概要

視聴者が次の金策案を送り、ステータス付きで一覧する。

## 機能要件

- [x] 名前任意、タイトル必須、本文10文字以上
- [x] honeypot と短いレート制限
- [x] ステータス: 募集中 / 検討中 / 採用 / 実施中 / 完了
- [x] 採用 / 実施中 / 完了のカードは押すと詳細。紐づく挑戦があれば収益・トークン代・介入も出す。企画の概要と note / YouTube は結果・明細の下の別カード。仕組みの本文は置かない
- [x] 完了した挑戦は一覧の「これまでの結果」へ。トップには全部並べない

## スコープ外

- 投票、収益分配
